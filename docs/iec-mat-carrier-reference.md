The HAL already contains RemoveNpcmHeader::parserNpcmHeader (Thumb VA 0xc436c). At 0xc4390–0xc43b0 it checks bytes 72 f8 1f 4e, followed by 16-bit little-endian Pc/Pd at 0xc43b8–0xc43ba. Pc=0x16 follows 0xc43d8–0xc43e0 and selects a 0xf000-byte burst; Pd stays byte-valued. This supports our FFmpeg MAT carrier framing. However, this is an audio dump processing path: mtk::AudioDataDump::npcmProcess (0xc3a40) calls constructor stub 0xd0b60 at 0xc3b28, RemoveNpcmHeader::removeNpcmHeader stub 0xd0b70 at 0xc3b5a, destructor stub 0xd0b80 at 0xc3b7c. Relocations 0xd3c94/98/9c map to those three symbols. removeNpcmHeader calls doSomeWorkV1 via stub 0xd0c20 at 0xc49a2, which calls doRemoveNpcmHeader via stub 0xd0c10 at 0xc4b02; parser called at 0xc45e2 (stub 0xd0c00). These are demonstrated debug-file call sites, not an AudioTrack write integration. Do not reuse the dump interface for playback.

## Offline reference

native/iec_mat_carrier.h is original C++17 code, narrowly scoped to the FFmpeg-generated 192 kHz / 8-channel / 16-bit MAT carrier: 61440 bytes = 20 ms, Pa=f872, Pb=4e1f, Pc=16, Pd=61424 bytes, MAT initial bytes 9e070300, eight zero padding bytes. Reject unknown/invalid/truncated frames; emit *whole unchanged bursts* only after validation. No payload stripping, decoding, transcoding, status-flag forcing or PCM fallback. This validates framing only, not the integrity or authenticity of internal Dolby metadata. No production HAL hookup yet. Callback reference is synchronous and atomic; real integration needs partial-write accounting, backpressure, HW sync timestamps, route changes, flush/standby and safe non-PCM signaling. Restrict to negotiated eARC capabilities; do not send arbitrary compressed data to speakers.

Local host test built with c++ -std=c++17 -Wall -Wextra -Werror -O2. Passed two synthetic header fixtures and nine full bursts generated by local FFmpeg TrueHD encoder from 0.2 seconds of stereo silence (not Atmos), including fragment sizes 1,7,8,4093,61440,100000, byte-for-byte roundtrip, header and padding corruption rejection, sink failure and reset. No ARM runtime, HAL, eARC or Atmos claim. Example:

    c++ -std=c++17 -Wall -Wextra -Werror -O2 tools/test_iec_mat_carrier.cpp -o /tmp/test_iec_mat
    /tmp/test_iec_mat
    /tmp/test_iec_mat samples/truehd.iec
